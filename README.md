# 🏰 地牢探险 - Roguelike Game

一个经典的肉鸽地牢探险游戏，使用纯 HTML/CSS/JavaScript 开发。

## 🎮 游戏特点

- **随机生成地图**：每层都是随机生成的房间和走廊
- **回合制战斗**：移动到敌人位置进行攻击
- **角色成长**：击败敌人获得经验值升级
- **装备系统**：收集武器和护甲增强实力
- **道具系统**：收集药水恢复生命值
- **楼层系统**：难度逐层递增
- **永久死亡**：死亡后从头开始

## 🕹️ 操作说明

| 按键 | 功能 |
|------|------|
| 方向键 / WASD | 移动 |
| 空格键 | 使用药水 |
| 移动到敌人位置 | 攻击敌人 |
| 移动到出口 | 进入下一层 |

## 🎯 游戏目标

- 探索随机生成的地下城
- 击败敌人获得经验和金币
- 收集装备提升实力
- 尽可能深入更多楼层

## 👾 敌人类型

| 敌人 | 生命值 | 攻击力 | 特点 |
|------|--------|--------|------|
| 🗽 哥布林 | 低 | 低 | 常见敌人 |
| 💀 骷髅 | 中 | 中 | 第2层开始出现 |
| 🐉 恶龙 | 高 | 高 | 第3层开始出现 |

## 📦 物品类型

| 物品 | 效果 |
|------|------|
| 🧪 药水 | 恢复生命值 |
| ⚔️ 武器 | 增加攻击力 |
| 🛡️ 护甲 | 增加防御力 |
